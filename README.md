# Tidelight

A static Three.js harbor. There is no game server. Opening the site joins a peer mesh; every visitor is a player in the same world. Donate compute and another islet rises.

**Play live:** [https://wjb000.github.io/tidelight/](https://wjb000.github.io/tidelight/)

Anyone who opens that URL loads into the same harbor. Share it and they can walk, wave, and chat with you.

```bash
npm install
npm run build
npm run preview
```

Then open the printed local or LAN URL. WASD walk, mouse look, E letter, type in the talk box and press Enter.

Characters are authored GLBs (`public/models`). Chat and pose ride the same mesh as presence.
